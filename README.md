# CTUC — Official Website

This is the official web app of **CTUC, the Cybersecurity Tunisian University Championship**.

CTUC is a national Capture The Flag (CTF) competition for university students across Tunisia. Teams of four solve
Jeopardy-style security challenges in web, binary exploitation, reverse engineering, cryptography, forensics, OSINT,
hardware and more. Two competitions run in parallel: a **Beginner CTF** and an **Advanced CTF**, so every student has
a place, whatever their level or field of study.

- **Date:** Saturday 28 November 2026
- **Venue:** Tunis Science City, Tunis
- **Who can join:** students of any Tunisian university

Organized by **Securinets iTeam University** and **Engineers Spark iTeam University**, powered by the
[FTSSU](https://www.fisu.net/nusf/tunisia/).

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
