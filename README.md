# CTUC — Official Website

This is the official web app of **CTUC, the Cybersecurity Tunisian University Championship**.

CTUC is a national Capture The Flag (CTF) competition for university students across Tunisia. Teams of four solve
Jeopardy-style security challenges in web, binary exploitation, reverse engineering, cryptography, forensics, OSINT,
hardware and secure coding. Two competitions run in parallel: a **Beginner CTF** and an **Advanced CTF**, so every student has
a place, whatever their level or field of study.

- **Date:** Saturday 5 December 2026, 16:00 to Sunday 6 December, 08:00 (overnight)
- **Entry:** free for iTeam University students; 5 TND (Beginner) or 10 TND (Advanced) per person otherwise
- **Venue:** UTICA, Tunis
- **Who can join:** students of any Tunisian university

Organized by **Securinets iTeam University**, **Engineers Spark iTeam University** and
[iTeam University](https://iteam-univ.tn/), powered by iTeam University.

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
